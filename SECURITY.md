# Security Policy

`russh-extra` is in pre-release development and does not yet have stable
supported versions.

Security-sensitive design and implementation rules live in
[`docs/dev/security.md`](docs/dev/security.md).

## Reporting a Vulnerability

Before the project configures private security advisories, report vulnerabilities
by opening a minimal public issue. Avoid exploit details in the public issue.
Request a private contact path and the maintainer will reach out.

## Supported Versions

No stable versions exist yet. Security fixes will be released as patch versions
of the latest pre-release once the project publishes to crates.io.

## Disclosure Policy

Vulnerability reports will be acknowledged within 7 days. Fixes will be released
based on severity. High-severity SSH protocol vulnerabilities will be prioritized
before other work.
