## Resolved Issues

- `Session::auth_banner()` now shares the same banner storage as the active
  `russh` client handler, so banners sent during authentication are visible
  after `Client::connect()`.
- Added loopback integration coverage for client auth banner capture.
- Updated README, roadmap, design docs, and ADRs so SFTP and forwarding status
  match implemented behavior.
- Replaced broad "complete russh coverage" release language with a 0.1.0 scope
  that covers main high-level workflows and documents raw escape hatches.
- Documented the publish order: `russh-extra-core` must be packaged and
  published before `russh-extra`.
- Added `release/**` to CI push branches so release branches receive the same
  checks as `main`.
- Made `async-trait` optional for default client-only builds.

## Remaining Risks

- `russh-extra` package verification without `--offline` depends on
  `russh-extra-core 0.1.0` being available from crates.io first.
- StreamLocal forwarding has implementation coverage but still needs additional
  loopback runtime tests; this is tracked in `docs/dev/roadmap.md`.
