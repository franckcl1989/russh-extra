## Resolved Issues

- **Security: X11Params Debug leaks X11 cookie** (Priority 0.1):
  Manual `Debug` impl in `shell.rs` redacts the X11 authentication cookie as
  `<redacted>`. Unit test asserts cookie is absent from formatted output.

- **Security: KeyboardInteractiveContext Debug leaks responses** (Priority 0.2):
  Manual `Debug` impl in `server.rs` shows `response_count: usize` and
  `responses: <redacted>`. Unit test asserts response bytes are absent.

- **Security: X11RequestContext Debug leaks auth cookie** (Priority 0.3):
  Manual `Debug` impl in `server.rs` redacts `auth_cookie` as `<redacted>`.
  Unit test asserts cookie is absent from formatted output.

- **Data loss: ShellAsyncIo silently drops stderr** (Priority 1.1):
  `run_channel_bridge` now routes `ChannelMsg::ExtendedData` to the read stream
  (interleaved with stdout, matching `ShellHandle` behavior). Unit test
  verifies stderr bytes are readable.

- **Resource leak: ShellAsyncIo bridge task never exits on drop** (Priority 1.2):
  Removed `_cmd_tx` self-referencing clone from bridge task construction. When
  `ShellAsyncIo` is dropped, `cmd_rx.recv()` returns `None` and the bridge task
  exits cleanly.

- **Correctness: KnownHosts::check short-circuits on first key mismatch**
  (Priority 1.3):
  `check()` now scans all entries for the hostname before returning `Changed`.
  A key match on any entry returns `Match`. Unit test verifies two entries for
  the same host with different key types.

- **Correctness: Credential::PartialEq for KeyboardInteractive returns false**
  (Priority 2.1):
  `KeyboardInteractive` variants now return `true` when compared, fixing `Eq`
  for `ClientConfig`. Unit test verifies config equality.

- **Deprecation: set_strict_host_key_checking destroys PinnedSha256**
  (Priority 2.2):
  Method is now `#[deprecated]` with guidance to use `set_host_key_policy`.

- **API contract: Pty missing #[non_exhaustive]** (Priority 2.3):
  Added `#[non_exhaustive]` to `Pty` struct.

- **API contract: TcpEndpoint/StreamLocalSpec missing #[non_exhaustive]**
  (Priority 2.4):
  Added `#[non_exhaustive]` to both structs. Struct-literal construction is
  no longer supported; use `new()` constructors.

- **API contract: Endpoint::Display breaks IPv6 round-trip** (Priority 2.5):
  `Display` now delegates to `authority()`, producing bracket notation for IPv6
  addresses. Unit test verifies parse-to-display round-trip.

- **CommandOutput::check_success** (Priority 3.1):
  Added `check_success(self) -> Result<Self>` returning `Err(Error::CommandExit)`
  for non-zero or missing exit status. Unit tests for exit 0 and exit 42.

- **Identity::key_file tilde expansion** (Priority 3.2):
  `key_file()` now calls `expand_tilde()` before storing the path. Unit test
  verifies `~` is expanded.

- **TerminalMode missing common SSH modes** (Priority 3.3):
  Added 13 new named variants (`Echo`, `EchoErase`, `EchoKill`, `EchoNl`,
  `CanonicalInput`, `SigCheck`, `CrToNlInput`, `NlToCrInput`, `IgnoreCrInput`,
  `PostProcessOutput`, `NlToCrNlOutput`, `CrToNlOutput`, `NoCrOnNl`).
  Added `#[non_exhaustive]` to the enum. Updated `terminal_mode_to_pty()`.

- **Comma-separated known-hosts hostnames** (Priority 3.4):
  `parse_host_pattern` now returns `Vec<(String, u16)>` and
  `KnownHostsEntry::parse` returns `Vec<Self>`. Comma-separated patterns
  produce one entry per hostname.

- **Test hardening** (Priority 4 partial):
  Added debug redaction tests for `X11Params`, `KeyboardInteractiveContext`,
  `X11RequestContext`, and `ClientConfig`. Added SftpServerHandler methods
  (`mkdir`, `rmdir`, `rename`, `readdir`, `fstat`) to `InMemorySftpHandler`
  with integration tests (6 tests, 5 passing, 1 `#[ignore]`).

## Remaining Risks

- `sftp_server_readdir_and_fstat` integration test is `#[ignore]`d — hangs on
  `opendir` handler dispatch. Not a production code bug; needs debugging.
  Deferred to 0.1.3.
- Large data tests, ShellAsyncIo lifecycle tests, and remaining SftpServerHandler
  method coverage (setstat, fsetstat, realpath, symlink) deferred to 0.1.3.
- Hashed known-hosts matching/writing, wildcard matching, `@cert-authority`
  validation remain deferred.
- Dynamic SOCKS-style forwarding and SFTP v4+ extensions remain deferred.
