# GitHub Labels

The label scheme groups issues and PRs by type, area, and status.

## Type

- `C-bug`
- `C-feature`
- `C-discussion`
- `C-docs`
- `C-test`
- `C-cleanup`

## Area

- `A-client`
- `A-server`
- `A-channel`
- `A-sftp`
- `A-tunnel`
- `A-macros`
- `A-ci`
- `A-docs`

## Status

- `S-needs-design`
- `S-designing`
- `S-ready`
- `S-blocked`
- `S-needs-tests`
- `S-breaking`
- `S-implemented`
