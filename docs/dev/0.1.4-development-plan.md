# 0.1.4 Development Plan

`0.1.4` is a hardening release and the final release in the `0.1.x` series. It
fixes the Windows CI regression, wires silently-ignored timeout configuration
on direct tunnel builders, improves SFTP error message quality, fixes base64
data integrity in known-hosts, adds `#[non_exhaustive]` to seven types missing
it, corrects `SftpErrorKind` misuse, deduplicates `map_channel_open_error`,
and fills documentation and observability gaps.

Workspace version: bumped from `0.1.3` to `0.1.4`.
MSRV: Rust `1.95`.
SSH dependency: `russh 0.60.3` (unchanged).

## Release Goal

Close out the `0.1.x` series with a version that has:
- Green CI on all three platforms (Linux, macOS, Windows).
- No silently-ignored configuration (timeout wiring).
- Accurate SFTP error messages (not `"SFTP request cancelled"` when the real
  cause is a protocol framing error).
- `#[non_exhaustive]` on all public types with exposed fields or that may
  gain new variants/fields in future releases.
- Correct `SftpErrorKind` usage (`Unsupported` for "not implemented" vs
  `UnsupportedVersion` for version mismatch).
- Tracing coverage across all major modules.
- Documentation that is fully consistent with the implementation.
