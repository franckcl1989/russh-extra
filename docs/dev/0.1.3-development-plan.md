# 0.1.3 Development Plan

`0.1.3` is a hardening release that completes deferred test coverage from the
`0.1.2` cycle, adds small API completions, fixes documentation drift, and
updates dependencies. It does not add new protocol features or change the
feature flag set.

Workspace version: bumped to `0.1.3`.
MSRV: Rust `1.95`.
SSH dependency: `russh 0.60.3` (upgraded from 0.60.2).

## Release Goal

Bring the crate to production-quality test coverage for core operations,
complete small API gaps identified in the 0.1.2 audit, and fix all documentation
consistency issues discovered during the 0.1.2 post-release cross-reference
audit.
